# Android-приложение NetSurvivors

27.10.2026, этап 8 (`docs/PLAN-FEEDBACK-27-10.md`). По образцу `docs/ANDROID.md` оригинала: игра в WebView через Capacitor 8,
APK ставится файлом, без Google Play.

## Как собрать

Из папки `D:\Utreys-NetSurvivors`:

```powershell
node tools/android-build.cjs
```

APK: `android\app\build\outputs\apk\debug\app-debug.apk` (≈ 68 МБ). Перед сборкой Gradle делает `clean`: иначе удалённые из игры
файлы остаются в APK.

Что делает скрипт:
1. Собирает статическую версию игры `dist/app/game` скриптом скилла ref2game `pack.py`. В ней выключены опрос сервера и панель
   разработчика.
2. Копирует её в Android-проект (`cap sync android`).
3. Собирает APK через Gradle.

Без сети: `$env:GRADLE_OFFLINE='1'; node tools/android-build.cjs` — всё нужное уже лежит в кэше Gradle (`~/.gradle`).

Откуда инструменты (ничего не скачивалось):
- **CLI Capacitor** — из оригинала, `D:\Utreys-Survivors\node_modules\@capacitor\cli`, только чтение.
- **Пакеты** `@capacitor/android`, `core` и `app` 8.x скопированы из оригинала в `node_modules/@capacitor`.
- **JDK** — из Android Studio (Java 25). Поэтому обёртка Gradle — 9.1.0, как в оригинале: шаблонный Gradle 8.14.3 с Java 25 не
  работает.
- **Android SDK** — `%LOCALAPPDATA%\Android\Sdk`.

## Что в приложении

- **Экран:** только альбомная ориентация (`sensorLandscape`), без системных панелей (свайп от края показывает их на время), экран
  не гаснет, пока приложение открыто (`MainActivity.java`).
- **Интерфейс:** включается компактный — крупный интерфейс для телефонов (этап 7б), управление пальцем (этап 7а).
- **Кнопка «Назад»:**
  - закрывает окно входа или сброса;
  - в смене открывает паузу, в паузе — продолжает;
  - на итогах ведёт в меню, на экране меню — на шаг назад;
  - в главном меню второе нажатие в течение 2 с закрывает приложение.
- **«Выход»** в главном меню закрывает приложение (`App.exitApp`).
- **Аккаунт и таблицы:** тот же проект Firebase `netsurvivors` (`live/firebase-config.js`). Страница открывается с адреса
  `https://localhost`, домен `localhost` в Firebase уже разрешён. Для входа и таблиц нужна сеть; без сети игра работает, забеги
  ждут в очереди.

## Как поставить на телефон

1. Скопируйте `app-debug.apk` на телефон (кабель, облако, мессенджер).
2. Откройте файл и разрешите установку из этого источника.

Отладочный APK подписан ключом этого компьютера: обновление ставится поверх, только если собрано здесь же.

Через кабель с включённой отладкой по USB:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r android\app\build\outputs\apk\debug\app-debug.apk
```

## Текстуры: размер и память

`python tools/shrink-assets.py` делает две вещи:
- **Убирает остатки генерации арта:** `*_gen` и `*_bodyonly`, 29 файлов, на них нет ссылок в коде.
- **Уменьшает текстуры:** до 640 px по длинной стороне, иконки — до 320 px. Игра и раньше рисовала их из атласа, урезанного до
  640 px. Логический размер берётся из манифеста (`live/assets.js`, `gl.js`), так что на экране ничего не сдвигается.

Итог: 145 → 57 МБ. Сравнение кадров QA до и после: средняя разница меньше 1,6 из 255, заметно изменилось не больше 0,08 %
пикселей.

Полноразмерные текстуры собираются заново из `art/gen` (`tools/ingest.py`). После нового арта запускайте `shrink-assets.py`
снова: он уменьшает только то, что ещё крупнее нужного.
