# Style passport — Utreys NetSurvivors (reference: zombie amusement park, re-themed to a datacenter)
View: 1920x1080 (ref 1280x720, x1.5), top-down 3/4 (~50 deg), smooth (not pixel art; finest detail ~1.2 px)
Game family: survivors-like arena (top-down action, hordes)      Style family: cel / comic with ink lines + light brush grain
Value: low-key, mean L* 24 (p5/p50/p95 = 2/19/66); actors and lit pools carry the highs
Light: cool blue-violet ambient (#161624..#3676da = 45%), warm amber pools from lamps (#b58d54 .. #f6bc56), key from upper left
Palette: blue-slate floor/metal ramp, warm orange ramp for lit props and fire, desaturated actor colours with saturated accents
Line: ~1 ref px (1.5-2 view px) dark warm ink #261215 / #0b090e around every object; actors inked by the engine
Shading: 2-3 hard tones, small hard highlights, grainy fill texture
Shapes: chunky cartoon, big heads (ref zombies ~55 ref px tall = ~85 view px)
Detail: focal at hero, explosion, boss; floor busy with litter decals but low contrast
Atmosphere: none fog; light pools and darkness do the depth; explosion = biggest bright mass
UI: chunky bars with dark backing top-left (HP red, XP blue + LV), big white bold timer top-centre, 3 square item slots bottom-centre, floating yellow combo text with ink stroke, giant stencil text painted on the floor
Datacenter mapping: cobbles -> raised-floor tiles; carousel -> round core router; kiosks -> server racks / security booth; bumper cars -> parked server carts; benches -> UPS units; trash cans -> PDU bins; lamp posts -> pillar lamps; gas cans -> coolant/battery tanks; zombies -> project's living objects (clients, bugs, panels)
